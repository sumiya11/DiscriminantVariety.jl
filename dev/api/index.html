Discriminant variety

DiscriminantVariety.discriminant_variety — Function
discriminant_variety(sys, vars, params; batch = 4) -> Vector{Vector}

Compute a discriminant variety of the system sys of K[params][vars], generically zero-dimensional in vars, with K either QQ (Nemo or AbstractAlgebra) or a prime field (Nemo).

The result is a list of components, each a list of polynomials in params of the ring of sys: the elimination ideal <sys, det(Jacobian w.r.t. vars)> ∩ K[params] and, for each variable of vars, the leading coefficients of the elements of a Groebner basis for DRL(vars) > DRL(params) whose leading monomial in vars is a pure power of that variable. Constant components are removed and components given by one polynomial are split into irreducible factors. An error is raised if sys is not generically zero-dimensional in vars.

batch: over QQ, the number of primes replayed together, one of 1, 2, 4, ..., 128 (batch = 1: one prime after the other).

Normalization of the components

DiscriminantVariety.postprocess — Function
postprocess(W_d; make_squarefree = true) -> Vector{Vector}

Normalize a list of components W_d, each a list of polynomials: remove the components containing a constant polynomial, split each component given by one polynomial into one component per irreducible factor (the factor itself if make_squarefree = true, the factor raised to its multiplicity otherwise), sort the components by maximal total degree and remove the duplicates.

This is the last step of discriminant_variety; it can be applied to a discriminant variety computed by other means to get the same normal form.
